API de réglages des projets

Probatiq offre à chaque site Jira une API pour lire et régler ses projets par programme : la colonne d'analyse, la livraison (dépôt GitHub, branche, URL de l'application testée, plan de charge) et la colonne de fusion avec son rôle. Mêmes contrôles et mêmes refus que l'écran du projet. Par conception, elle ne touche jamais à l'exécuteur, aux secrets, aux packs de normes ni à l'exploration, et ne déclenche aucune analyse.

Avant d'appeler

  1. L'adresse est propre à votre site. Elle est affichée sur la page « Exécuteur Probatiq » de votre Jira, carte « Accès API aux réglages des projets ». Elle n'apparaît pas sur cette page.
  2. Un accès se délivre sur cette même carte, par un administrateur du site. Sa valeur, préfixée pqa_, s'affiche une seule fois ; elle vaut pour tous les projets du site jusqu'à sa révocation. Traitez-la comme un mot de passe de service.
  3. Une seule route : POST sur l'adresse, en-tête Authorization: Bearer <valeur>, corps JSON {"operation": "…", "projet": "CLE", …}.

Cette page est une documentation de lecture : l'essai d'un appel se fait depuis votre outillage (Postman, Insomnia, Bruno, curl), en important le fichier OpenAPI ci-dessous et en y renseignant l'adresse de votre site. Aucun accès n'est saisi ni conservé ici.
